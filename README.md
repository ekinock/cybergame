## Architecture
```text
cybergame/
├── README.md
├── index.html       -> le menu de départ
├── style.css        -> fichier principal à modifier pour Leev
├── images/
│   ├── toutes les images que je vais utiliser
│   └── je peux rajouter des trucs si besoin
├── scenario1/
│   └── index.html   -> les index dans les dossiers scenarioX sont générés par twine
├── scenario2/       -> il vaut mieux ne pas y toucher, histoire de rien casser
│   └── index.html   -> je modifie juste une ligne moi pour que le css général soit lu
├── scenario3/       -> mais rien de plus
│   └── index.html   -> il y a des balises de style en + ; c'est des trucs pour l'affichage 
├── scenario4/       -> de twine ; pareil, ne pas toucher vu qu'on ne sait pas ce qu'elles font
│   └── index.html
└── credits/         -> ça c'est pas encore fait, mais je le rajouterai au menu à la fin
    └── index.html   -> je mettrai les outils utilisés + le gens qui ont participé
```

## Ressources pour Leev
### Ressources graphiques
charte graphique CHU : \
https://www.calameo.com/read/00737844676d1cacf9d2b \
pages 21 à 29 \
-> tu trouveras les couleurs avec les bons codes, les polices, etc etc

### Trucs à faire en priorité
- mettre les bonnes polices \
- mettre les bonnes couleurs \
-> fait sur une base sombre ou claire, comme tu préfères \
-> si tu as envie de faire les deux ; c'est chouette mais c'est pas obligé \
*(et honnêtement je ne sais pas si c'est possible dans ce contexte de proposé à l'utilisateur de choisir clair ou sombre donc bon)* \
-> tu n'es pas obligée de prendre toutes les couleurs, prend celle qui te font plaiz & que tu trouves jolies \
- rajouter une classe avec du texte en petit, genre pour les notes de bas de page, les commentaires, etc

### Trucs secondaires
- tu peux retaper le menu de l'index général si tu as envie / des idées \
-> je n'ai pas de contrainte particulière si ce n'est que ça reste lisible & qu'on puisse bien choisir entre les différents scénarios \
- si t'as la deter tu peux faire apparaître le logo du chu (avec l'étoile) et celui de l'école (cesi) sur le fond ou en bas \
-> juste si tu fais ça, fait moi confirmer le logo de l'école parce qu'uls arrêtent pas de changer faut que ce soit le dernier \
si t'as d'autres idées, hésite pas
